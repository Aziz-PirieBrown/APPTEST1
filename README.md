# 局域网极速探测跳转 App (V3.5 双模联动版)

## 项目简介

这是一个 Android 辅助工具，通过 **"基准点扩散扫描"** 与 **"UDP 抓包监听"** 双模并行技术，极速锁定局域网内指定端口（默认 34832）的 HTTP 服务，并实现自动跳转。

## 核心特性

### 1. 双模并行探测

- **快车道 (P0)**：立即探测基准点 IP，成功则秒跳
- **主动扫描 (P1)**：基准点扩散模型，以 Base IP 为中心，沿 X/Y 轴按设定步长并发探测
- **被动抓包 (P1)**：实时监听 UDP 广播包，从捕获的局域网数据包中提取源 IP 并验证端口

### 2. 智能配置管理

- 所有配置项支持**失去焦点自动保存**
- 每个字段独立记忆**最近 5 条历史记录**
- 清空内容自动删除配置
- 支持自定义浏览器包名（默认荣耀浏览器）

### 3. 灵活的扫描参数

- **起始 IP**：192.168.X.Y 格式，X 和 Y 独立输入
- **Y 轴偏移**：上/下偏移量和步长
- **X 轴偏移**：上/下偏移量和步长
- **端口**：默认 34832
- **路径**：默认 /board，可选 /wewewe
- **并发数**：80/100/120 可选
- **延迟**：0s/1s/2s/3s/5s 可选

## 构建说明

## 使用说明

### 1. 首次启动

应用启动后会自动读取配置并开始探测：
- 首先尝试快车道探测基准点
- 如果基准点不可达，则同时启动主动扫描和被动抓包

### 2. 重新探测

点击 **[重新探测]** 按钮：
- 清空所有日志
- 同时启动 UDP 抓包监听和 X/Y 轴全维度扩散扫描

### 3. 停止扫描

点击 **[停止]** 按钮：
- 立即终止所有扫描协程及 UDP 监听任务
- 日志显示：`[停止] 用户手动中断。`

### 4. 自动跳转

- 无论是扫描发现还是抓包提取的 IP，只要通过端口验证
- 立即停止所有任务
- 按设定的延迟秒数跳转到指定浏览器

## 技术实现

- **开发语言**：Kotlin
- **异步框架**：Coroutines + Dispatchers.IO
- **扫描引擎**：java.net.Socket，超时 300ms
- **抓包引擎**：DatagramSocket 监听局域网广播
- **并发控制**：Semaphore 信号量
- **配置存储**：SharedPreferences

## 权限说明

应用需要以下权限：
- `INTERNET`：网络访问
- `ACCESS_NETWORK_STATE`：网络状态检测
- `ACCESS_WIFI_STATE`：WiFi 状态检测

## 版本信息

- **版本号**：3.5

- **目标 Android 版本**：14 (API 34)

## 注意事项

1. 确保设备已连接到局域网
2. 扫描范围较大时，建议使用较高的并发数（120）
3. 被动抓包功能依赖于局域网中的 UDP 广播流量
4. 如果指定的浏览器未安装，会尝试使用系统默认浏览器
